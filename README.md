# Dynamic Mathematical Clock

An interactive canvas clock built with JavaScript and p5.js that transforms digital timekeeping into a visual geometric experience using polar coordinates.

## 📌 About the Project
Dynamic Mathematical Clock uses trigonometric angle mapping and polar coordinates to draw concentric, continuous radial arcs representing elapsed hours, minutes, seconds, and fractional milliseconds. Instead of traditional hands, time is visualized as expanding radial trajectories around a clean centered digital readout and polar-aligned numerals.

## 🛠️ Languages, Tools & Software Used
- **Languages**: JavaScript (ES6+), HTML5, CSS3
- **Libraries & APIs**: [p5.js](https://p5js.org/) (Creative Computing & HTML5 Canvas)
- **Softwares & Tools**: Visual Studio Code, Git, GitHub, Modern Web Browsers (Chrome, Edge, Firefox)

## ✨ Key Features
- **Trigonometric Coordinate Mapping**: Dynamically calculates radial positions and sweep arcs using polar-to-Cartesian trigonometry ($\sin\theta$, $\cos\theta$).
- **Continuous Millisecond Sweep**: High-speed inner arc mapped to fractional milliseconds ($0$ to $1000\text{ ms} \rightarrow 0^\circ$ to $360^\circ$) for smooth, fluid motion.
- **Synchronized Calendar & Digital Clock**: Displays standard 12-hour AM/PM time and live date.
- **Client-Side Rendering**: Pure client-side execution with zero dependencies or server requirements.

## 🚀 How to Run
Simply open `index.html` directly in any modern web browser or serve it using the VS Code Live Server extension.
